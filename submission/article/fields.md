LaptopAdvisor: Using Strands Decider 2B for Tool Selection in a Laptop Recommendation Agent
Description (max 512 characters):
LaptopAdvisor is a conversational agent that helps anyone find the right laptop by describing their needs in plain language. Strands Decider 2B picks which tool to call for each request — search by use case, compare two models, filter by budget, or fetch full specs — before Amazon Nova Pro on Amazon Bedrock responds. The result is a 5.5x faster routing decision with 100% accuracy when confident.
